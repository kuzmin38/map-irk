# Бот «Помощник сантехника» — УК «Жемчужина» (мессенджер MAX)

Рабочий бот звена сантехников УК «Жемчужина» (Андрей, Константин, Александр). Умеет:

- 🔍 **Поиск дома по адресу** — пишете адрес («Розы Люксембург 118/5»), бот отвечает,
  наш ли это дом, и даёт кнопки-ссылки на 2ГИС и Яндекс.Карты.
- 🏘 **Наши дома по ЖК** — дома группируются по комплексам УК: Квадрум, Академия,
  Квартал, Центральный парк, Жемчужина, Четыре солнца. Привязка дома к ЖК —
  кнопкой «Указать ЖК» в карточке дома.
- 📁 **Документы домов (оцифровка)** — прямо в бота можно прислать фото, скан или
  файл техдокументации, он привяжет её к дому (кнопка «Добавить документ»).
  Файлы хранятся в `bot/data/docs/<id дома>/`, список — в базе.
- 📋 **Заявки** — создание (адрес → описание), статусы «новая → в работе → выполнена»,
  список открытых и выполненных. Хранятся в SQLite (`bot/data/bot.db`).
- 🗂 **Электронные паспорта домов** — техданные по каждому дому (розливы, диаметры,
  запорная арматура, доступ в подвал и т.д.). Заполняются прямо из бота кнопкой
  «Редактировать» и сохраняются в базе.
- 📅 **Работы и дедлайны** — по каждому дому: опрессовка, сдача теплового узла,
  дефектовка, закупка материалов. У работы есть срок, ответственный (из звена),
  статус «план → в работе → сдано» и заметка. Общий список сортируется по срокам,
  просроченные помечаются ⚠️ и поднимаются наверх. Состав звена — `bot/data/team.json`.
- 📖 **Справочник** — телефоны, нормативы (ПП № 354), предельные сроки устранения
  (Правила № 170), шпаргалка по диаметрам труб. Правится в `bot/data/directory.json`.

## 1. Создание бота в MAX

Боты создаются через бизнес-кабинет **business.max.ru** (MasterBot больше
не создаёт ботов сам, а отправляет туда же).

1. Зайдите на business.max.ru → «Создание бота».
2. Заполните: название (например, «Люся»), ник (латиницей, 11–60 символов,
   окончание `_bot`), телефон компании и сайт — поля обязательные.
3. После создания бот уходит на модерацию (обычно до 1–2 рабочих дней);
   токен доступа виден в настройках бота в кабинете.
4. Скопируйте **токен** — он понадобится ниже. Никому его не показывайте.

## 2. Установка

Нужен Python 3.10+.

```bash
git clone https://github.com/kuzmin38/map-irk.git
cd map-irk
pip install -r requirements.txt
```

## 3. Запуск

### Локально / для проверки (long polling)

```bash
export MAX_BOT_TOKEN='ваш_токен'
python -m bot.main
```

### На VPS через вебхук

Вебхуку нужен публичный HTTPS-адрес. Проще всего поставить nginx + certbot
и проксировать на порт бота:

```bash
export MAX_BOT_TOKEN='ваш_токен'
export BOT_MODE=webhook
export WEBHOOK_PORT=8080
export WEBHOOK_URL='https://ваш-домен.ru/'   # бот сам зарегистрирует подписку в MAX
python -m bot.main
```

Пример nginx:

```nginx
server {
    listen 443 ssl;
    server_name ваш-домен.ru;
    # ssl_certificate ... (certbot)
    location / { proxy_pass http://127.0.0.1:8080; }
}
```

### Автозапуск (systemd)

Скопируйте `deploy/santehnik-bot.service` в `/etc/systemd/system/`,
впишите свой токен и путь, затем:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now santehnik-bot
```

## 4. Обновление данных о домах

Список домов (`bot/data/houses.json`) генерируется из карты `index.html`:

```bash
python3 scripts/extract_houses.py
```

Запускайте после обновления карты — список домов подтянется сам.

## 5. Что можно править без кода

- `bot/data/directory.json` — телефоны, памятки, нормативы (впишите реальные
  номера диспетчерской и аварийки вместо прочерков).
- `bot/data/houses.json` — список домов (лучше через `scripts/extract_houses.py`).
- `bot/data/complexes.json` — список ЖК управляющей компании.
- Паспорта домов, заявки, привязки к ЖК и реестр документов живут в
  `bot/data/bot.db`, сами файлы документов — в `bot/data/docs/`.
  Обе папки стоит регулярно бэкапить.
