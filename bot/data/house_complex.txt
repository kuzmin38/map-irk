# Привязка домов к жилым комплексам.
#
# Формат: адрес = id комплекса. Всё после # — примечание.
# Адрес пишется как в houses.json; регистр, «ё» и слова «ул.», «дом»
# значения не имеют.
#
# Возможные id комплексов (из complexes.json):
#   kvadrum       — ЖК Квадрум
#   akademia      — ЖК Академия
#   kvartal       — ЖК Квартал
#   cpark         — ЖК Центральный парк
#   zhemchuzhina  — ЖК Жемчужина
#   4sun          — ЖК Четыре солнца
#
# Дом, которого здесь нет, просто остаётся без комплекса — это не ошибка:
# часть домов стоит отдельно и ни в какой ЖК не входит.
#
# Пример:
#   4-я Советская 30 = 4sun
#   Седова 65а/2 = zhemchuzhina
#
# Файл читается при старте и заполняет только те дома, у которых комплекс
# ещё не проставлен. Привязка, сделанная руками в боте, не перезаписывается.
